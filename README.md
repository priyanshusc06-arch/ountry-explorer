# Country Explorer

A responsive web application built with HTML, CSS, and Vanilla JavaScript that fetches live country data from the REST Countries API.

## Features
- Search any country by name (with Enter key support)
- Filter countries by region (Africa, Americas, Asia, Europe, Oceania)
- Dark / Light mode toggle saved in `localStorage`
- Recent searches saved as quick-click chips in `localStorage`
- Responsive CSS Grid layout for mobile, tablet, and desktop
- Error handling for empty inputs, invalid searches, and network failures

## Technologies Used
- HTML5 (Semantic Elements)
- CSS3 (CSS Grid, Flexbox, CSS Variables)
- JavaScript (ES6+, Fetch API, `async/await`, `localStorage`)

## API Used
- [REST Countries API](https://restcountries.com/)
